# Scope Client data by Relationship Manager

MVP ให้ RM เห็นเฉพาะ Client ที่ `rm_id` ตรงกับผู้ใช้ใน session และตรวจ ownership ในทุก endpoint รวมถึง Family Wealth Network เพื่อให้ข้อมูลสังเคราะห์มีขอบเขตการเข้าถึงที่สมจริงและทดสอบได้ การเลือกนี้ทำให้การแสดงสมาชิกครอบครัวที่ RM อื่นเป็นเจ้าของต้องปกปิด แม้ข้อมูลจะอยู่ในฐานข้อมูลเดียวกัน
